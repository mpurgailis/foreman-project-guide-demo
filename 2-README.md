# Foreman Project Guide concept

An independent, non-production concept for Foreman Locker Systems. This is a two-minute guided qualifier, not a locker configurator.

## What it demonstrates
- Qualifies application, environment, quantity, project stage and timing.
- Sets expectations for very small requests before sales time is spent.
- Gives larger 15-49 and 50-100+ projects a material-family starting point.
- Produces a compact sales handoff without asking the buyer to design every locker.
- Submits no data and contacts nobody.

## Libraries.dev usage
The live UI uses the [`thinking-orbs`](https://libraries.dev/orbs.html) React package from Libraries.dev for the assistant's breathing/searching states. The package is imported from esm.sh in `index.html`.

## Run locally
Serve `index.html` from any static web server, for example:

```bash
npx serve .
```
